# 汇报模式与分页

## 三类汇报

论文精读回答研究为何提出、方法如何实现、证据是否充分和能否借鉴。主线可为研究问题、相关方法差异、核心方法、实验与局限、个人理解和讨论。论文结果标为作者报告，改进设想标为个人建议。

实验复现回答实现与论文是否一致、运行条件是否可比和差异发生在哪里。主线可为复现目标、原文基线、实现与环境、实际结果、差异诊断、补充实验和讨论。没有代码或日志时不声称检查或运行过。

阶段进展回答相对上次新增什么、证据是什么、卡点在哪里和下阶段如何验收。主线可为上次目标与本次增量、关键实现、实验与负结果、问题讨论和计划。没有上次材料时不生成历史进度。

混合组会可用论文方法支撑本人实验，不重复背景，也不强行填满所有模式模块。

## 常用模块

M1研究问题与本次目标：必要背景、现有不足、输入输出、本次研究问题。

M2方法与理解：技术路线、关键机制、符号含义、实现接口或论文理解。

M3实验与进展证据：配置、数据、对照、结果、失败记录与新增产物。

M4问题讨论与下一步：现象、候选解释、区分实验、需要决定的选择和验收。

模块是组织工具，并非每次都独立成章。纯论文精读不强加本人进展，单次调试可以围绕一个失败现象组织。

## 动态分页

1. 一页一个问题，优先一张主要证据图配一个有限结论。不同实验问题或不同量纲一般分开。
2. 复杂方法按模块定义、关键机制与验证三段落展开，页数按内容决定。
3. 本页保留必要公式及变量定义，长推导、全量参数与结果可放附录。
4. 听众已知的背景只保留与新结果有关的部分。没有新增证据的重复成果页优先删除。
5. 结果、解释与计划分开表述；未验证的原因标为候选。
6. 短组会可删除目录和所有过渡页，不按原模板槽位补页。
7. 指定N页默认指总计N页；附录是否另计按用户要求。未指定时说明实际页数即可。
8. 指定时长时按内容估计讲解与讨论用时，不采用固定每分钟页数。

## 可选分页示例

论文精读：封面、问题、相关方法差异、总体架构、关键机制、实验设置、结果、消融与局限、可借鉴之处、讨论。复杂机制可续页。

复现组会：封面、复现目标、原配置、本地实现差异、实际环境、结果、误差定位、失败假设、补充验证、下一步。

阶段进展：本次目标、完成增量、关键实现、实验设置、结果、负结果与诊断、待讨论选择、下阶段验收。短汇报可以目标页直接开场。
