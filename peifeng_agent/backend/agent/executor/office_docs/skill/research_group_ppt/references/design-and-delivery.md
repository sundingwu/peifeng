# 版式与交付检查

## 科研版式

优先用户设计。默认16比9、白底深蓝标题和清晰正文，可复用蓝白模板。减少宣传图、团队展示和无必要过渡页，让方法、证据和讨论成为中心。

正文优先约18至24pt，内容超载先删冗余或拆页。公式足够大，同一符号前后含义一致。坐标轴、单位、图例和误差定义要能读。

正文、表格和数据图表可编辑。复杂示意图按用户要求处理，原图保持比例并标来源，不以整页截图交付可编辑PPT。

## 套版与核对

1. 先 `pptx(describe_template=true, template="<本 SKILL.md 所在目录的绝对路径>/assets/reference-template.pptx")` 看每页锚点与槽位计数。
2. 生成时用 `pptx(template=..., slides=[{template_page, replace, drop, images, notes}])`：`replace` 按锚点换文案并保留原字体字号，带 ×N 的槽位把新值写成数组按顺序填，`drop` 清掉多余槽位，`images` 按厘米定位贴图。
3. 回执会给出每页用的模板页、换了几段文案、清了几个占位、贴了几张图、备注多少字。
4. `read` 回读 .pptx，逐页核对文案、公式符号、页码与章节编号。

## 模板边界

优先复用对应布局和母版。删除占位、示例数据、无关英文及活动。学校校徽和校园照片仅在身份匹配时使用；单位未知时删除身份素材，保留通用蓝白结构。

装饰层作为背景时，正文与图表用可独立编辑的对象。模板的 27 页是版式库，页数由内容决定；团队、SWOT、金额、完成率这几类页面按研究需要决定取舍。

## 交付验收

1. 渲染全部页面，检查换行、孤立标点、公式、轴标、截图、两位数页码、越界和重叠。
2. 核对内容覆盖、原文与本人结果边界、数据口径、结论边界、讨论和计划验收。
3. PPTX图片须实际嵌入，媒体文件非空且关系有效，不依赖本机路径。原生图表包含必要的数据和工作簿。
4. 重新打开或导入实际交付文件，验证图片、字体、表格与图表完整。预览正确不代替文件检查。
5. 修复后复查受影响页。无法完成的核验如实说明，不声称PowerPoint验证，除非确实打开检查过。

交付用户要求的PPTX或方案，不附临时图片、脚本和验证日志，不添加未经请求的产业收益、经费或知识产权。
