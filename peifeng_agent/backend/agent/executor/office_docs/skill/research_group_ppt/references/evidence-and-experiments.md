# 科研证据与实验口径

## 证据分类

论文报告是作者在给定设置下的结果，须注明论文与表图章节位置。按作者报告的口径写，注明出处。

本人实测来自已提供日志、数据或本次确实运行的结果，须可追溯到配置与记录。未运行脚本不算实测。

代码阅读只描述实际读到的实现；只看了论文时按论文口径写。

个人理解、候选原因和改进建议与事实分开写，未验证的原因标为假设。计划与预期画成虚线或单独标注。

## 对比与统计

核查数据、划分、样本量、预处理、指标实现、训练预算、搜索预算、参数、随机种子、硬件和计时范围。影响结论的缺项保留限制，不补默认配置。

不同单位、归一化与方向换算到同一口径后再比较；相对变化写明分母。80%到85%是提升5个百分点，相对提高6.25%；20秒到15秒是缩短25%。

测试算例组方差、单次运行内波动和多训练种子方差属于不同统计单位，不互相替代。统计显著以原始数据与有效检验为依据；误差条与置信区间按实际计算结果给出。

综合分数改善只支持给定权重下的总体评价，不证明所有单项均改善。仿真、离线实验与部署收益分开。推断、训练与端到端时延分别标明计时范围。

## 复现差异

先对照原论文与本地实际配置，再报告原值与差距。条件不同时按受限观察写，说明哪些条件一致、哪些不一致。

将预处理、指标实现、模型结构、超参数、预算和随机性作为候选原因，设计能区分解释的实验。因果结论需要能区分解释的实验支撑；随机性只作为候选原因之一。

## 图片与引用

原方法图、系统截图和实验图保留比例、图例与必要标识。来源写入对应页备注，影响结论的限定留在页面。

重绘结果依据真实数据；曲线上的读数按原图精度给出，标明是估读。材料冲突时并列版本与各自口径。
