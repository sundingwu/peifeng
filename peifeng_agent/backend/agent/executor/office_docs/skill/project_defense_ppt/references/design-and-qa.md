# 样式与验收

## 模板实测与使用规则

1. 画布 16:9（13.333×7.5 英寸）；封面与致谢页用同组背景图片与曲线，内容页有章节数字与左上标题，章节页带 PART 编号。
2. 显式文字色有 #063772、#579ACD，其余继承主题；套版时沿用模板自带配色。
3. 原模板显式字号 12、20、28pt 较多，那是原文件特征；投影正文按 18—24pt 排，超出容量先删冗余再拆页。
4. 沿用它自己的标题栏、装饰与图文比例，保证对齐、留白与章节编号一致。
5. 把「建设项目介绍」「重点完成进度」这类通用标题换成当前页的具体主题。

## 内容验收

逐页检查：有没有明确问题；上屏文字是否可直接用；主图或表是否定义完整（轴、列名、单位、图例）；有没有来源；实绩、计划与假设是否分清；与上一页是否重复；后续行动是否对上问题。

数据检查：分母、单位、时间范围、样本量、划分方式、对照方法、评价方向齐全；提升百分比与提升百分点分开写；单个指标支撑不了全面优越的结论。

覆盖检查：M1 说明问题与方案；M2 展示成果证据或验证设计；M3 含限制与改善路径；M4 含任务、时间与验收。

## 文件与版式验收

1. 回读 `.pptx` 的文本，逐页核对文案、章节编号与实际页码。
2. 看落盘回执：每页用了哪个模板页、换了几段文案、清了几个占位、贴了几张图、备注多少字。
3. 核对图片已真正嵌入（回执里有贴图张数；回读文本能对上图题）。
4. 生成页数与目录、章节编号一致。
5. 交付说明里写清未完成的核对与缺项，例如缺渲染检查、缺某页素材。
