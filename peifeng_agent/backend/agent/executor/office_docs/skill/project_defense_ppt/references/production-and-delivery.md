# 制作与文件交付

## 资源与输出边界

1. `assets/reference-template.pptx` 是版式来源；生成的 .pptx 是它的副本改造，原模板保持不动。
2. 默认沿用蓝白色调、画幅、封面曲线、章节页与页眉层级。单位标识与校园图片在本项目单位匹配时保留，其他单位换成当前材料的内容或用 `drop` 清掉。
3. 用户给了自己的模板或明确风格时按用户要求执行。页数由内容决定，模板的 27 页只是版式库。
4. 旧项目的论文、截图、联系方式与实验数据属于旧项目；新项目用新项目的材料。

## 可编辑性与图片

1. 正文、表格、定量结果图表用模板里的可编辑对象；照片与截图按原比例嵌入，用 `images` 的 `width_cm` 控制宽度。
2. 模板页的照片槽位多为形状占位：先用 `drop` 清掉占位文本，再用 `images` 按厘米定位贴图。
3. 图片随 .pptx 一起保存（回执里的「贴图 N 张」可核对）；复杂公式或流程图按材料给的原图保留比例并标注来源。

## 交付与核对

1. `pptx` 回执给出每页的模板来源、换文案段数、清占位个数、贴图张数与备注字数，逐项过一遍。
2. `read` 回读 .pptx，核对每页文本、目录与页码。
3. 交付用户要求的 .pptx 与一段说明；调试脚本与验证日志放在会话中间目录。
4. 缺少素材或无法完成的核对，在交付说明里写清哪一页缺什么。

## 信息不足时

1. 没有时长或页数时，按材料完成叙事并说明实际页数。
2. 缺少真实实验结果时展示验证设计，提升率留到有数据时再写。
3. 没有确定时间表时，可以给相对启动日期的建议阶段并标注为建议。
4. 缺少成员职责时列已知身份。
