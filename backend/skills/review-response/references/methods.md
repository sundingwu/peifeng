# 审稿意见到可核验修订

先识别编辑决定及用户要整包、路线、局部润色还是覆盖审计；仅有意见就规划，未做实验不写已补。拒稿后策略与可修改返修分开；没有真实邀稿/决定不能冒称被要求修回。

## 逐点映射
按编辑/Reviewer及原编号保留原意见，复合意见拆子项但保留父编号。分为表达/文献/方法/实验/统计/伦理/格式/范围/误解等，记录关注点→作者行动→证据→稿件位置→状态→回复。主跟踪表内部用，每位审稿人的回复独立，不泄漏另一互盲审稿人的原话；投稿信面向编辑概括关键变化。

回复结构：简短感谢或直接确认→实质回答→已完成变化及位置→证据/边界。能做的请求给实际修改，不能做的解释科学原因、可用替代证据和剩余局限；合理反对针对论点，不讨好、不对抗、不许诺无资源实验。冲突意见按编辑要求与研究逻辑协调，保留取舍说明。

## 修订与覆盖审计
revision-coach输出优先级路线、依赖和作者待办；已有rebuttal-audit只比原意见与现有回复，不自动重写。逐项判已覆盖/部分/遗漏/证据不足/误解/过度承诺，核图表与文本实际存在、数据一致、页行号和干净/标记稿匹配。只改一句时不强制重建整包。

标记稿不能以“改动说明”冒充真实修订；Word用document-formatting的修订/XML能力，LaTeX保留宏和源码不编译。实际包一致性可交Mentor的response_package审计；不自行调用未注册skill。没有证据的承诺标待完成，不能用精确语气掩盖未知。
