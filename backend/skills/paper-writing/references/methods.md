# 论证、章节与修订

## 证据边界与精简修改
先锁定章节、语言、篇幅和证据；术语/符号/缩写统一。用一句话表达系统/问题、推进、方法、支持和边界，不能写出则先标核心缺口。正文、附件与修改说明同一主张强度，不把unsupported改成disproved，不补造方法、来源或结果。

段落围绕主张→证据→解释→连接展开。修改按问题定位和最小补丁进行，保留原稿、改动位置与实际版本；无缺陷不循环同义替换。图/表展示精确值，正文解释关系，不重复所有数字或过长局限。新增算术要有实际复算，未知单位/方向不说分、百分比或优劣。小样本、ID交集与缺失机制的推断按数据设计，不笼统否定所有检验。

## 章节功能
| 章节 | 最短必要论证 |
|---|---|
| 标题/摘要 | 一个有界主张，问题→核心推进→1–2项决定性支持→意义；数字只选必要且已核值 |
| 引言 | 问题漏斗→关键文献张力→具体知识缺口→研究问题→简短路线；不是堆领域热度 |
| 相关工作 | 按概念/机制/路线比较最近似工作与真实差异，不把篇目清单当论证 |
| 方法 | 输入输出/假设→整体流程→承重模块→实现与代价；每模块说明为何需要及支持 |
| 结果 | 按待证明问题组织实验，先条件/比较再发现，局部解释不越证据；稳健性服务主张不堆测试 |
| 讨论 | 主要发现锚点→与已有解释对话→意义与替代解释→具体局限→对应未来验证，逆漏斗展开 |
| 结论 | 回答研究问题与适用边界，不引入新结果 |

研究/发现论文强调证据，方法/算法论文强调公平预算、复现和成本，假说论文列可证伪预期，资源论文列覆盖/质量/访问，临床/材料论文交代设计与适用范围，综述/观点分清综合与主张；章节结构随任务调整，不强制统一IMRaD。

## 起草、润色与教学模式
从头写作可先给提纲和主张—证据表；已有文本润色只改语言/结构，不重做研究；中译英先转论证关系再表达，保留否定、量词、时态与may/suggest/show强度。双语摘要逐项对齐，关键词不凭空添加研究领域。用户要revision-coach时先将意见分解为修改路线/作者待办；已有回复的覆盖核验交review-response，审稿判断由Mentor。

## 引用与投稿材料
引用键稳定，每个引用可定位，不因“期刊风格”添加未经核实文献。APA/Chicago/MLA采用作者年等相应结构，IEEE/Vancouver保留数字编号与排序；实际要求以目标venue为准。Nature、Nature Communications、NMI不可共用未经核实的字数/格式限制。首次投稿信、标题页、亮点、贡献/伦理/数据/AI声明由submission-check按实际政策准备，复审往来用review-response。LaTeX只交源文件，不编译。
