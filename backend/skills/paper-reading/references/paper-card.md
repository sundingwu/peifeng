# 十六节精读卡

仅在用户要完整精读卡时采用。页前至少7行`>`状态字段：来源、读取范围、论文类型、定位模式、图表可用性、补充材料、提取/证据缺口；不以模板补猜。定位模式恰选page-grounded、structure-grounded或source-limited。实质主张用`[Paper: PDF p.3]`、`[Paper: section Methods]`或`[Paper: abstract]`等真实定位；结构/摘要模式不造页码。

| 标题（按01–16） | 内容 |
|---|---|
| 01 基本信息 | 版本、题录、标识符、代码/数据与缺失字段 |
| 02 一句话 | 问题—方法—有界发现 |
| 03 研究问题 | 具体问题、意义与不足 |
| 04 背景路径 | 阶段、路线和当前位置，标外部已核验或作者叙述 |
| 05 核心痛点 | 表现、解释、论文证据 |
| 06 核心思路 | 表面方法、关键洞见、可迁移分析分别列 |
| 07 方法概览 | 输入输出、模块、训练/工具、假设 |
| 08 模块拆解 | 作用、必要性、接口、移除效果及实测/预期区别 |
| 09 公式符号 | 必要公式、符号、直觉、来源；不适用明确说 |
| 10 实验与证据链 | 设计/数据/预算/指标；实验→主张→条件→结果→支持上限→来源 |
| 11 正确结论 | 范围、oracle输入、端到端与否、成本、依赖和不确定性 |
| 12 作者局限 | 仅作者明确承认的局限与定位 |
| 13 批判分析 | 标[Analysis]，具体替代解释、影响及验证 |
| 14 学到的知识 | 可迁移概念、方法、公式与设计，标模型提炼 |
| 15 已有知识联系 | 用户知识、已核文献与候选联系分开 |
| 16 研究候选 | 来源观察、假设、相对差异、如何验证、可能失败、创新状态 |

卡片不附17/18节或自测、公众号稿。作者局限不明不能移入分析冒充。创新状态写unverified/partially checked/prior-art checked，最后一种须有实际检索。

extract_pdf.py的source_bundle=true可给页证据包；模型仍需实际查看关键图表并补充已核验清单，空清单不证明没有图表。Mentor的research-review/scripts/audit.py用operation=paper_card、path、bundle、locator_mode检查；未经该角色审核不自称已通过。结构检查不证明语义支持。
