# 数据与统计

## 数据交付与科学解释
先声明实验单位、字段、指标方向/单位、业务键和缺失/重复/失败处理；10与10.0按数值等价去重，冲突不静默择优。记录原始/排除/可用数量，保留输入、配方和验证。记录数、实体数、组数、交集分别计算；范围是最小到最大，极差是两者差。格式描述与实际代码一致，浮点定点格式化不冒称Decimal ROUND_HALF_UP。

ID交集只证明重叠，不证明分数污染；不重叠不证明独立。失败集中于某组不证明缺失非随机。未知单位或指标方向只报原始尺度与有符号差，不能擅称分、百分比或改善。描述、显著性、总体外推和因果分开；配置未验证不能归因于单一机制。

## 统计报告与方法选择
逐分析记录：终点、实验单位、独立/技术重复、配对/重复测量/批次、纳排、缺失、随机化/盲法、变换、模型、假设、比较族、估计/区间/p/n、软件版本。技术重复不能冒充独立样本；各图n定义、误差类型和检验与正文一致。

按设计选独立/配对、参数/稳健/非参数或层级模型；不是看一次正态检验就自动选择。多重比较先定义比较族与预设比较，再选校正；不能事后择显著结果。检验提供实际效应与不确定性，不把p解释为假设为真概率、效应大小或临床重要性。非显著不证明等效，等效/非劣须预设界值与合适检验。

小样本意味着精度有限，不否定所有推断；功效/区间未算就不评高低宽窄。样本量按精度/功效和资源假设，不固定至少5或10。验证断言只检查协议、恒等式和已知事实，不要求差值恒定、非零、同号或显著。

脚本内置describe/Welch/paired/固定效应meta；其他效应量、功效、校正、重复测量、回归、稳健估计需按明确方案写项目Python并验证，不伪称已有CLI参数。

## 荟萃分析
先统一结局、效应方向、效应量及方差，识别重复报告、重叠样本、多臂和相关结局。固定/随机效应选择来自目标与异质性假设，不由显著性决定。内置meta只做正方差的固定效应逆方差合并；随机效应、亚组、敏感性、发表偏倚另按方案实现，条件不足不强行汇总。交付提取表、转换依据、合并值/区间、Q/I²及适用边界；GRADE/偏倚评估属于研究判断，不由合并脚本自动给分。
