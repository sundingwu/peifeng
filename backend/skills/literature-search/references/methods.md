# 发现、排序与追踪

## 检索策略
把概念、人群/任务、干预/方法、对照、结局和范围拆开，合并同义词/缩写/中英文表达；需要MeSH时核对正式主题词、层级和自由词，以OR扩同义、AND联概念，NOT谨慎使用。给可复现的PubMed检索式，不声称已经执行MeSH查询。跨学科用桥接概念与相邻方法，并做参考文献/施引追踪。

先查用户给定材料和标识符；公开网页用Bing/DuckDuckGo，论文元数据用Crossref、arXiv、PubMed。说明源特性与覆盖，搜索排序不等于质量。记录检索式、来源、日期、版本、筛选原因、去重依据及实际读取范围；近似题名不能拼接字段。

## 六维候选排序
用户需要文献短名单或触发追踪时，可用原项目默认权重：主题35、方法20、来源15、研究网络相关10、应用10、留用10，各维不超过上限，总分复算。原方案主题<10即排除，仅在采用该方案时使用；用户可改权重和阈值。每维给可核对理由，声望/被引量不能代替方法质量，网络相关需与用户关注的作者/机构有实际关系。分数是筛选启发式，不是创新性证明；信息不足标未知，不凑分。

短名单提取WHY/HOW/WHAT，再比较共同瓶颈、路线分歧、反证和未解决问题。空白要解释知识后果与可检验证据，不把本次没查到写成无人研究。

## 检索停止与来源范围
按所需字段决定停止：DOI一致、权威记录齐全且无矛盾即可交付，不为未要求的卷期/引用次数反复抓同一JSON。元数据、摘要、公开页、全文提取、仅下载分别标记；未返回字段只称本次未读，转载同一元数据不算独立证据。异常、限流、解析失败不是零结果；具体矛盾才补查。引用UTC ISO时间戳，不把本地小时标UTC。

仅需题录时，核验字段齐全就停止，不再尝试出版社全文。同一站点返回403、反爬或限流后，不通过改URL大小写、编码或查询参数反复访问；记录失败并使用已获证据。需要全文时可尝试一个合法公开存档来源，仍不可得就明确读取限制。

## 增量追踪
只在用户触发时按已有主题、截止时间和上次清单运行；按DOI/版本去重，给新增、相关变化和重叠风险，保留失败来源。若请求完整报告再深读组织，否则直接交付短名单与来源。无定时器、推送、账号连接或自动长期归档。
